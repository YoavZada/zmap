# v0.7.0 — GeocoderControl (place search) + JSDoc polish

**Date:** 2026-07-23
**Status:** Approved (design), pending implementation plan
**Baseline:** main after v0.6.0 + follow-ups (zmapgl 0.6.0 on npm, d897a40).
**Branch:** `feat/v0.7.0-geocoder`

## Problem

zmap has no place search. Every map product wants "type a city, fly there",
and today consumers must hand-roll a search box, a geocoding client, camera
moves, and a result marker. The upstream `maplibre-gl-geocoder` plugin
renders its own non-MUI DOM, so theming it fights the library's premise.
Separately, the docs props tables render a **blank** description cell for any
prop without JSDoc (`PropsTable.tsx` renders `prop.description` verbatim from
`props.json`), and several exported types have undocumented fields (e.g.
`ContextMenuItem` — 4 of 5 fields bare).

## Decisions (locked with user)

1. **Photon is the zero-config default** (komoot's free OSM geocoder — built
   for search-as-you-type, CORS-open, keyless). Fair-use public instance;
   the provider interface is the self-host/swap escape hatch.
2. **On select: fly + drop marker**, both togglable via props;
   `onSelect(result)` always fires.
3. **Built-ins: `photon` + `nominatim`** behind a public `GeocodingProvider`
   interface for custom backends. Nominatim configured policy-compliant
   (1100 ms debounce ≈ ≥1 req/s; docs note to self-host for production).
4. **Architecture: headless `useGeocoder` hook + thin MUI Autocomplete
   control** (matches the `useDraw` precedent; hook is publicly exported).

## Workstreams

### W1 — Geocoding provider layer (`packages/zmap/src/providers/geocoding/`)

New directory mirroring the style-provider pattern
(`providers/types.ts` + const map + resolver):

```ts
// providers/geocoding/types.ts
export type GeocodeResult = {
  id: string;           // stable per provider, e.g. "node:123456"
  name: string;         // primary label
  address?: string;     // secondary line ("city, state, country")
  placeType?: string;   // provider's type, e.g. "city", "street"
  center: LngLatTuple;  // [lng, lat]
  bbox?: [number, number, number, number]; // [west, south, east, north]
  raw?: unknown;        // provider's raw result object
};

export type GeocodeOptions = {
  signal: AbortSignal;
  limit?: number;
  language?: string;
  proximity?: LngLatTuple; // bias center, [lng, lat]
};

export interface GeocodingProvider {
  id: string;
  search(query: string, options: GeocodeOptions): Promise<GeocodeResult[]>;
  attribution?: string;
  /** Minimum trimmed query length before searching. Default 2. */
  minQueryLength?: number;
  /** Debounce between keystroke and request. Default 300. */
  debounceMs?: number;
}
```

```ts
// providers/geocoding/index.ts
export const geocoders = { photon, nominatim } as const;
export type GeocoderId = keyof typeof geocoders;
export type GeocoderInput = GeocoderId | GeocodingProvider;
export function resolveGeocoder(input: GeocoderInput): GeocodingProvider;
```

**`photon.ts`** — `https://photon.komoot.io/api?q={q}&limit={n}`
(+ `&lang=` when `language` set, + `&lat=&lon=` when `proximity` set).
Maps GeoJSON features → `GeocodeResult`:
`center` = `geometry.coordinates`; **`bbox` from `properties.extent`, which
Photon returns as `[minLon, maxLat, maxLon, minLat]`** → reorder to
`[extent[0], extent[3], extent[2], extent[1]]`; `id` =
`` `${osm_type}:${osm_id}` `` (index fallback); `name` = `properties.name`
(street+housenumber fallback); `address` = join of
city/state/country (minus duplicates of `name`); `placeType` =
`osm_value ?? osm_key`. `debounceMs: 300`, `minQueryLength: 2`,
`attribution: "Search data © OpenStreetMap contributors"`.

**`nominatim.ts`** — `https://nominatim.openstreetmap.org/search?q={q}`
`&format=jsonv2&limit={n}` (+ `&accept-language=` when set; Nominatim has no
proximity-bias param — `proximity` is ignored). Maps array items:
`lat`/`lon`/`boundingbox` are **strings**, `boundingbox` order is
`[south, north, west, east]` → parse floats, reorder to
`[bb[2], bb[0], bb[3], bb[1]]`; `name` = `name || display_name` first
segment; `address` = remainder of `display_name`; `placeType` = `type`.
`debounceMs: 1100`, `minQueryLength: 3`, same attribution.

Tests (node env, `*.test.ts`, `vi.stubGlobal("fetch", …)`): exact URL/params
per option combination, response mapping incl. both bbox reorders, non-OK
response → thrown error, `resolveGeocoder` for ids/objects.

### W2 — `hooks/useGeocoder.ts` (headless, public)

```ts
export type UseGeocoderOptions = {
  limit?: number;    // default 5
  language?: string;
  /** Bias center; a getter is read at request time (fresh map center). */
  proximity?: LngLatTuple | (() => LngLatTuple | undefined);
};
export type UseGeocoderResult = {
  query: string;
  setQuery: (query: string) => void;
  results: GeocodeResult[];
  loading: boolean;
  error: Error | null;
  clear: () => void; // aborts in-flight, resets query/results/error
};
export function useGeocoder(
  provider?: GeocoderInput,        // default "photon"
  options?: UseGeocoderOptions,
): UseGeocoderResult;
```

Semantics (exact):
- Query is trimmed. Below `minQueryLength`: cancel pending timer, abort
  in-flight, `results=[]`, `loading=false` — no request.
- At/above: (re)start the provider's `debounceMs` timer; on fire, abort the
  previous `AbortController`, create a new one, `loading=true`, call
  `provider.search(query, { signal, limit, language, proximity })` with
  `proximity` resolved (getter invoked) at request time.
- `AbortError` rejections are swallowed; only the latest request may set
  state. Other errors: `error` set, `results=[]`, `loading=false`.
- Unmount: clear timer + abort. No fetch ever runs before user input
  (SSR-safe; no module-scope browser APIs).

Tests (`*.test.tsx`, jsdom, `vi.useFakeTimers()` + mocked fetch): debounce
window respected, rapid typing aborts prior request, stale response dropped,
min-length gate, clear(), error path.

### W3 — `components/GeocoderControl/`

`GeocoderControl.tsx` + `geocoderControl.style.ts` + `index.ts` barrel.
Rendered as a `<Map>` child (mounts only after `loaded` — Map gates
children), absolutely positioned like `MapControls` (zIndex 2, corner
offsets), reusing `ControlPosition` imported from `"../MapControls"`.

```ts
export type GeocoderControlProps = {
  /** Corner of the map. Default "top-left". */
  position?: ControlPosition;
  /** Built-in id or custom provider. Default "photon". */
  provider?: GeocoderInput;
  /** Input placeholder (and accessible label). Default "Search places…". */
  placeholder?: string;
  /** Fly the camera to a picked result. Default true. */
  flyTo?: boolean;
  /** Target zoom when the result has no bbox. Default 14. */
  zoom?: number;
  /** Drop a Marker at the picked result. Default true. */
  marker?: boolean;
  /** Max results. Default 5. */
  limit?: number;
  /** Result language hint, passed to the provider. */
  language?: string;
  /** Bias results toward a point. Default "map-center". */
  proximity?: "map-center" | LngLatTuple | false;
  /** Fires when the user picks a result. */
  onSelect?: (result: GeocodeResult) => void;
  /** Fires when the input is cleared. */
  onClear?: () => void;
  /** Empty-state text (also shown on provider errors). Default "No places found". */
  noOptionsText?: string;
};
```

Composition: MUI `Paper` (matches MapControls panel look) wrapping
`Autocomplete` (deep imports: `@mui/material/Autocomplete`,
`@mui/material/TextField`, `@mui/material/InputAdornment`,
`@mui/icons-material/Search`). Server-filtered:
`filterOptions={(x) => x}`, `getOptionLabel` → `result.name`,
`isOptionEqualToValue` by `id`, `popupIcon={null}`, built-in clearable.
Listbox rows render `name` + secondary `address`. `open` is controlled:
focused AND trimmed query ≥ provider min length. `loading` wired from the
hook. Errors render as the `noOptionsText` empty state (the hook exposes
`error` for headless users; no toast). Width 280px, `maxWidth`
`calc(100% - 16px)` — style file, not a prop.

Behavior on select: `proximity` resolved via `map.getCenter()` getter when
`"map-center"`; camera — `result.bbox` →
`map.fitBounds([[w, s], [e, n]], { padding: 40 })`, else
`map.flyTo({ center, zoom })` (same imperative pattern as the MapControls
geolocate button); `marker` → render internal zmapgl `<Marker>` (default
themed pin) at the result, replaced on next pick, removed on clear.
Clearing calls `onClear` and aborts/resets via the hook's `clear()`.
The control renders no attribution UI; `provider.attribution` is documented
(OSM basemaps already display OSM attribution).

**Test-infra prerequisite:** `packages/zmap/src/test/mockMaplibre.ts` has no
`flyTo` — add it (apply center/zoom to camera state, like `easeTo`), and add
`getCenter` if missing. Component tests follow the `TimePlayback.test.tsx`
pattern (`MapContext.Provider` + `FakeMap` wrapper, jsdom): renders input,
typing populates the listbox (mocked provider), select → `flyTo`/`fitBounds`
called with expected args + marker present, `flyTo={false}` → no camera
call, `marker={false}` → no marker, clear → `onClear` + marker removed.

## Risks

- **Photon public instance is best-effort/fair-use** — mitigated by the
  provider interface (self-host or swap), docs note, and offline demo for
  e2e determinism.
- **Nominatim policy** (no heavy autocomplete on the public instance) —
  1100 ms debounce + docs note; not the default provider.
- **Bundle growth** — measured against size-limit with an explicit budget
  policy (W4); Autocomplete cost lands only on consumers who import
  GeocoderControl (tree-shaking preserved, proven by the `{ Map }` budget).
- **Photon/Nominatim response-shape drift** — mappers are unit-tested
  against recorded fixture JSON; `raw` passthrough is the consumer escape
  hatch.
