# zmap starter

A minimal Vite + React + [MUI](https://mui.com/) app with a themed
[zmapgl](https://www.npmjs.com/package/zmapgl) map.

## Use it

```bash
npx degit YoavZada/zmap/templates/vite my-map-app
cd my-map-app
npm install
npm run dev
```

Docs & live demos: <https://yoavzada.github.io/zmap>
