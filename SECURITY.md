# Security Policy

## Supported Versions

We support the **latest minor release** of `zmapgl`. Security fixes are
released as a new patch on top of the latest minor; older minors do not
receive backports.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately using GitHub's built-in advisory flow: go to the
[Security tab](https://github.com/YoavZada/zmap/security) of this repo and
select **"Report a vulnerability"** to open a private security advisory.
GitHub notifies maintainers directly and keeps the report out of public view
until a fix is ready.

We aim to acknowledge new reports and provide an initial response within
**7 days**. If the report is confirmed, we'll coordinate a fix and a
disclosure timeline with you before publishing.
